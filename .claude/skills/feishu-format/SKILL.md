# 飞书文档格式规范

## 图表（关键规则）

**不要用 ASCII 文字图**——飞书只会原样显示字符，不会渲染成画板。

所有架构图、流程图、时序图统一用 Mermaid 语法生成。

### Mermaid 在飞书中的渲染限制

**飞书的任何导入方式（编辑器「上传及导入」/ `docx_builtin_import` API）都不会把 ` ```mermaid ` 块转成画板**，统一识别为普通代码块。这是飞书导入引擎的限制。

**唯一可靠的方式**：在飞书编辑器中手动插入绘图块：
1. 光标定位到目标位置
2. 输入 `/绘图`，选择「画板」
3. 将 Mermaid 代码粘贴进去

因此，生成含架构图的文档时：
- 正文文字、表格、标题 → 正常导入（任意方式）
- Mermaid 图表 → 导入后提示用户在飞书编辑器手动替换为 `/绘图` 块，并附上对应的 Mermaid 代码方便粘贴

### 飞书支持的 Mermaid 类型

以下类型在飞书 `/绘图` 块中均可正常渲染：

| 场景 | Mermaid 类型 |
|------|-------------|
| 系统架构 / 模块关系 | `graph LR` 或 `graph TD` |
| 业务流程 / 测试流程 | `graph` / `flowchart TD` |
| 时序 / 接口调用链 | `sequenceDiagram` |
| 模块关系 / ER 图 | `erDiagram` |
| 甘特图 | `gantt` |
| 状态机 | `stateDiagram-v2` |

## 其他格式规则

- **标题层级**：最多用到 `###`，不用四级以上
- **表格**：标准 markdown 表格，飞书正常支持
- **代码块**：加语言标识（` ```python `、` ```bash ` 等）
- **图片**：只用已上传到飞书的 URL，不用本地路径
- **加粗 / 斜体**：`**粗体**` / `*斜体*`，飞书正常渲染
