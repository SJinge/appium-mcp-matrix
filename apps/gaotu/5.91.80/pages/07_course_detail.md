# 课程详情页

- **层级**：depth 1
- **导航路径**：上课 tab → 我的课程 → 点击课程卡（如「测试1v1」）
- **页面特征**：React Native 页面（`reactNativeFragment`）。顶部课程名 + 过期时间 + 主讲 + 工具入口（学习资料/考试/错题本）+「课程/服务」Tab + 课节列表
- **截图**：`screenshots/07_course_detail.png`

## UI 区域与关键元素

### 顶部信息
| 元素 | 定位 | 说明 |
|------|------|------|
| 返回 | 左上角 `<` | |
| 课程名 | content-desc=`测试1v1` / `text=测试1v1` | |
| 过期时间 | content-desc=`过期时间：` | |
| 主讲 | content-desc=`石金鸽, 主讲` | 头像 + 姓名 + 角色 |

### 工具入口（横排）
| 工具 | 定位 |
|------|------|
| 学习资料 | content-desc=`学习资料` |
| 考试 | content-desc=`考试`（含红点角标）|
| 错题本 | content-desc=`错题本` |

### 内容 Tab
| Tab | 定位 | 说明 |
|-----|------|------|
| 课程 | content-desc=`课程` | 默认选中（下方课节列表）|
| 服务 | content-desc=`服务` | 课程服务 |
| 课程目录 | content-desc=`课程目录` | 右侧目录入口 |

### 课节列表
| 元素 | 定位 | 说明 |
|------|------|------|
| 课前准备（分组）| content-desc=`课前准备` | 可折叠 |
| 课节1 | content-desc=`1. B课节1B, 未观看  \|  06月24日 今天16:00-16:05` | 状态「未观看」+ 时间 |
| 课节1-去练习 | content-desc=`去练习` / `text=去练习` | 红色按钮 |
| 课节2 | content-desc=`2. B课节2B, 06月25日 明天16:00-16:05` | 锁定态（未到时间）|
| 摸底测 | content-desc=`摸底测, 请在 2027年06月25日 周五10:46 完成` | 测验入口 |

> 课节 content-desc 形如「序号. 课节名, 状态 \| 日期 时间段」；点击进课节详情/播放页。

## 可导航子页面（depth 2）
- 课节卡 → 课节详情/播放页（见 `pages/08_lesson_detail.md`）
- 去练习 → 练习/答题页
- 学习资料 → 资料列表
- 考试 → 考试列表
- 错题本 → 错题本
- 摸底测 → 测验页
- 服务 Tab → 课程服务页
- 课程目录 → 章节目录抽屉
