# 首页子 Tab：关注 / 圈子

- **层级**：depth 1
- **导航路径**：首页 → 顶部子 Tab「关注」/「圈子」
- **截图**：`screenshots/02_home_guanzhu_timelimit.png`、`screenshots/03_home_quanzi_timelimit.png`

## 探索结果：被青少年浏览时长限制拦截

切换到「关注」「圈子」子 Tab 时均弹出 **「浏览时间限制」** 弹窗，内容区不可访问。

> ⚠️ **重要环境前提**：本设备（26KUT24202013751）登录账号处于**青少年模式**，且当日浏览时长已达上限。
> 表现为社区/信息流类内容（关注、圈子）被时间限制弹窗覆盖。课程学习类页面（上课、我的）不受影响。

### 弹窗元素
| 元素 | 定位 | 说明 |
|------|------|------|
| 标题 | text=`浏览时间限制` | |
| 正文 | 「今天浏览时长达到限制,无法继续使用,请合理安排时间...」 | |
| 返回首页 | xpath `//*[@text='返回首页']` | 关闭弹窗回到推荐 |
| 前往设置 | xpath `//*[@text='前往设置']` | 跳转青少年模式设置页 |

### 弹窗后透出的内容（受限，仅作结构参考）
- **关注**：关注的作者动态信息流（图文帖子，含作者名 + 日期）
- **圈子**：圈子分类（小初高等）+ 帖子卡片列表

- 帖子卡片 → 帖子详情 / 短视频流（受限未访问）
