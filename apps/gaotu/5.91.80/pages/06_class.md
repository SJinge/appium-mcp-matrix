# 上课 Tab

- **层级**：depth 0（底部 Tab，默认落地页）
- **导航路径**：底部导航 → 上课
- **页面特征**：顶部标题栏（错题本 / 课程表 / 更多）+「今日学习推荐」横滑卡 +「我的课程」筛选器 + 课程列表
- **截图**：`screenshots/06_class.png`

## UI 区域与关键元素

### 顶部标题栏
| 元素 | 定位 | 说明 |
|------|------|------|
| 标题 | `text=上课` | |
| 错题本 | content-desc=`错题本` / `text=错题本` | 跳错题本 |
| 课程表 | content-desc=`课程表` / `text=课程表` | 跳课程表 |
| 更多 | 标题栏右侧 `···` | 更多菜单 |

### 今日学习推荐（横滑卡）
| 元素 | 定位 | 说明 |
|------|------|------|
| 区块入口 | content-desc=`今日, 学习推荐` | 含 `text=学习推荐` |
| 翻页指示 | content-desc=`1/2` / `text=1/2` | 当前 1/2 |
| 推荐课节卡 | content-desc=`第1讲 小灶课, 数学 · B课程中心gps1.5-线上回归B北京市` | 点击进课节 |
| 推荐课节卡 | content-desc=`第1讲 B课节1B, 数学 · 测试1v1` | 已完成（绿勾）|

### 我的课程（筛选器 + 列表）
| 元素 | 定位 | 说明 |
|------|------|------|
| 区块标题 | `text=我的课程` | |
| 课程类型筛选 | content-desc=`课程类型` | 下拉 |
| 年级筛选 | content-desc=`年级` | 下拉 |
| 科目筛选 | content-desc=`科目` | 下拉 |

#### 课程卡（长按出「置顶 / 隐藏」操作）
| 元素 | 定位 | 说明 |
|------|------|------|
| 课程卡1 | content-desc=`数学     测试1v1, 数学, 共2节, 下次课 明天16:00` | 含主讲「石金鸽」+ 班主任「王思敏03」|
| 课程卡2 | content-desc=`数学     B课程中心gps1.5-线上回归B北京市, 数学, 共2节` | 含主讲「石金鸽」|
| 置顶 | content-desc=`置顶` | 左滑/长按露出 |
| 隐藏 | content-desc=`隐藏` | 左滑/长按露出 |

> 课程卡 content-desc 形如「科目  课程名, 科目, 共N节, 下次课 时间」；点击进课程详情页。

## 可导航子页面（depth 1）
- 错题本 → 错题本页
- 课程表 → 课程表页
- 课程卡 → 课程详情页（见 `pages/07_course_detail.md`）
- 学习推荐课节卡 → 课节详情/播放页
