# AI闪学 Tab

- **层级**：depth 0（底部 Tab）
- **导航路径**：底部导航 → AI闪学
- **页面特征**:顶部连胜徽章 + 热门好课横滑卡 + 学习工具宫格 + 限时活动 banner + 闪学课程推荐瀑布流
- **截图**：`screenshots/05_ai_flashlearn.png`

## UI 区域与关键元素

### 顶部连胜徽章
| 元素 | 定位 | 说明 |
|------|------|------|
| 连胜入口 | content-desc=`0, 0, 天连胜` | 含「0」(`text=0`) + 「天连胜」(`text=天连胜`) |

### 热门好课（横滑卡 `HorizontalScrollView`）
| 元素 | 定位 |
|------|------|
| 区块标题 | `text=热门好课` |
| 查看全部 | content-desc=`查看全部` / `text=查看全部` |
| 课程卡（示例）| content-desc=`《西游记》AI阅读-新课标整本书原著阅读, 和悟空一起打怪升级` |
| 课程卡（示例）| content-desc=`米小圈AI动画课堂开课啦, 边学边乐，上头的知识宝藏` |
| 课程卡（示例）| content-desc=`高途阅读｜亲子共读20本经典世界名著, AI智能加速，成长快人一步` |
| 课程卡（示例）| content-desc=`《列那狐的故事》AI 阅读-新课标整本书原著阅读, 在幽默冒险中点亮思辨之光` |

> 课程卡为 B 端动态配置，content-desc 形如「标题, 副标题」。

### 限时活动
- 区块标题 `text=限时活动`，下方为活动 banner（动态内容）。

## 可导航子页面（depth 1）
- 热门好课 → 查看全部 → 闪学课程列表页
- 课程卡 → 闪学课程详情/学习页（AI 阅读 / AI 动画课）
- 句句背单词 → 背单词工具页
- 听一听 → 音频课列表
- 创意空间 → 编程作品页
- 资料 → 资料库
- 查看更多 → 学习工具全部入口
