# UI 样式规范

> 每次 ASSERT 截图时检查，发现任意一条不符合则 ui_pass=false。  
> 由 [assert_spec.md](assert_spec.md) 的 Q3 调用。

---

## 检查项

### 1. 元素完整性（不截断）

- 所有可见元素的边缘不得被屏幕边界裁切
- 重点：最右侧元素右边缘、最底部元素下边缘、弹窗四边
- 典型问题：输入框/按钮/图标只露出一半，内容溢出屏幕可视区域

### 2. 布局越界

- 元素不得超出父容器或屏幕边缘
- 多个同类横排元素（如验证码输入框、tab 图标）：所有元素须等宽、等间距，且**全部在屏幕内**

### 3. 文字截断 / 溢出

- 文本不得被容器截断（出现省略号"..."时需确认是否为预期设计）
- 重点：按钮文案、标题、列表 item 内容

### 4. 元素遮挡

- 关键操作元素（按钮、输入框）不得被其他层级遮挡
- 弹窗不得遮住后续需要操作的主体内容（除非为预期交互）

### 5. 对齐与间距

- 同行/列元素应对齐，不得出现明显错位
- 元素间距应均匀，不得某一处明显偏大或偏小

### 6. 图片 / 图标加载

- 图片不得显示为空白、破图（灰色占位符）或错误图标
- 图标不得显示为方块、问号或乱码

---

## 逐项判断

```
1. 所有元素边缘完整，无被屏幕裁切？
2. 横排同类元素最右侧元素右边缘在屏幕内？
3. 无文字截断（非预期省略号）？
4. 无关键元素被遮挡？
5. 元素对齐、间距无明显异常？
6. 图片/图标正常加载，无破图？

ui_pass = 全部 yes → true，任意 no → false
```
