# Case Flow Script Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace generated Android case scripts with executable `FLOW` scripts and add a shared `run_flow()` runtime that can replay full business flows instead of page-snapshot assertions.

**Architecture:** Keep flywheel execution driven by Feishu cases, but change the generated script format from `ASSERTIONS` to `FLOW`. `scripts/orchestrate.py` becomes the single runtime owner: it interprets `FLOW`, handles basic state prep/dialog rules/assertions, and still keeps a short compatibility path for old scripts while migration completes.

**Tech Stack:** Python 3, pytest, existing `scripts/orchestrate.py` runtime, generated Python case files under `apps/gaotu/cases/android`.

```python
def _flow_from_case_steps(case: dict) -> list:
    flow = []
    for step in case.get("steps", []):
        if step.get("type") == "PRECOND":
            continue
        if step.get("script_action") and step.get("locator"):
            flow.append({
                "type": step["script_action"],
                "by": step["locator"].get("by"),
                "value": step["locator"].get("value"),
            })
            continue
        if step.get("type") == "ASSERT" and step.get("passed") and step.get("confidence") == "high":
            flow.append({
                "type": f"assert_{step['verify_method']}",
                "value": step.get("evidence"),
                "soft_assert": is_toast_like_assert(step),
                "text": step.get("text", ""),
            })
    return flow
```
